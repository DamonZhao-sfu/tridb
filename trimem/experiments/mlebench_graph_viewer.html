节点 / relational：代码、任务、会话、阶段、执行耗时、异常、CV 分数与评分方向。历史语料的 is_valid=true 表示可索引，fitness=0 是占位值；执行成功与否记为未知。
lineage / native graph：本地 journal 用 node2parent 恢复真实父子关系，不能把时间相邻的尝试直接连边。历史 version 表示版本演化；fork 单独保留。导入时写原生图邻接结构。
similar / vector + graph：历史 code_sim 是来源提供的关系，不是本次 triMEM embedding top-k 或 LLM 判断。它可作为带来源的独立边类型导入；新的 triMEM similar 边需要选定 embedding、阈值和跨 session 策略后计算。
semantic op：可在候选上比较改动、失败原因与可迁移性。已有 summary / transition 能作为输入，但不代表已经运行了 triMEM 语义算子。
历史人类 session 继承自来源 tree_id，不一定等于单个 notebook 或一次执行。CV 与 held-out 仅在节点详情分别显示；held-out 不参与本图布局、连边或检索。US Patent 和 Ventilator 的历史库全部来自人类 notebook。执行修复示例仅指 buggy 父节点 → 非 buggy 且有 CV 的子节点，不代表最终任务已解决。相似边默认关闭以便看清演化结构；勾选后显示当前范围内全部来源关系。
