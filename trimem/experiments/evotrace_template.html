Telemetry first or semantic first?

Three agent-memory retrievals over EvoTrace (10,672 attempts, native lineage and cross-session similarity graphs, code embeddings). For each, TriMEM's planner estimates every placement of the LLM semantic filter, and every placement is then run with Qwen3.8-27B to check the choice.

“Pushing a cheap telemetry filter before a semantic judge can reduce LLM invocations, whereas an early, highly selective semantic filter may avoid an expensive traversal. Choosing between these plans requires estimating both the cost and selectivity of relational and semantic operators.” (TrajectoryDB, arXiv 2609.07782)
